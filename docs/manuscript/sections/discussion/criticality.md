The criticality proxy track provides a target shape for future empirical adapters: if real data are introduced, the same validator should require source identity, preprocessing provenance, and negative controls. A future empirical adapter would compute measured branching and avalanche-size summaries over reviewed activity series and compare them against histogram-preserving shuffled controls. Power-law-like avalanche summaries would not by themselves establish criticality, because similar scaling can arise without a critical state and cortical-criticality evidence remains method-sensitive [@touboul2017power_law_absence_criticality; @destexhe2021criticality_evidence]. The branching index is a software-trajectory diagnostic that names what a criticality test would measure; it remains outside the empirical evidence class until reviewed data, preprocessing provenance, and ethics constraints exist [@wilting2019criticality].
