# docs/ Agent Invariants

Agent guidance for the flat `docs/` folder. The documentation contract
(`check_documentation_contract` in `src/gates/validation.py`, run via
`scripts/check_documentation_contract.py --check`) enforces these rules.

## Generated docs are not hand-edited

These files are produced by the chain. Edit the generator, not the document:

- `equation-crosswalk.md` — generated by `scripts/generate_equation_crosswalk.py`
  from `formalism_registry.json`.
- `method-inventory.md` — generated by `scripts/generate_method_inventory.py`.

Every other `docs/*.md` is hand-edited prose.

## No orphans

Every reference doc in `docs/` must be linked from a navigation hub — either the
project `README.md` or `docs/README.md` — via a Markdown link to its filename.
A doc that no hub links to fails the no-orphan guard. `README.md` and
`AGENTS.md` are exempt (they are hubs / guidance, not reference docs). When you
add a doc, add its link to `docs/README.md` in the same change. Do not edit
`docs/README.md` solely to satisfy this rule without a real navigation entry.

## No machine paths (fail-closed)

No absolute home-directory machine path may appear on any line of a tracked
doc, including this file. Use `<template-checkout>` or a repository-relative
path. This guard is fail-closed: a single absolute-path occurrence fails the
contract.

## Links must resolve

Local Markdown links in `README.md`, `AGENTS.md`, and `docs/README.md` must
point at files that exist. Broken local links fail the contract.

## Claim ceiling

Keep docs within the project claim ceiling: finite deterministic software
surrogates only, with no empirical, clinical, neural, ontological, awakening,
practice-efficacy, or physical qFEP claims. Plain ASCII Markdown.

Note: `docs/README.md` is the docs hub and is maintained directly; do not
restructure it as part of unrelated changes.
