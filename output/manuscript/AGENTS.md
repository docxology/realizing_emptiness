# Manuscript Agent Invariants

Editing rules for the `realizing_emptiness` manuscript. Violations fail the
manuscript gates in `src/gates/manuscript.py` and `src/gates/validation.py`.

## Edit fragments, not composed files

- The top-level `00_abstract.md` through `06_supplement.md` are generated by
  `scripts/compose_manuscript.py`. Never hand-edit them.
- Edit the per-track fragments under `sections/<section>/<track>.md` and the
  per-section `_lead.md` signposts.
- Treat this file as the manuscript-level hub: shared fragment rules live in
  `sections/AGENTS.md`, while sheaf shape and track order live under `sheaf/`.
- Recompose from the project root after any fragment change:

  ```
  uv run python scripts/compose_manuscript.py --strict
  ```

  `--strict` fails on any missing manifest fragment.

## Claim ceiling

Make no empirical, clinical, neural, ontological, awakening, practice-efficacy,
or physical qFEP claims. Everything is a finite deterministic software
surrogate. Keep claim-bounding language in the prose, not just in gates.

## Acronyms and the abstract

- Define every acronym at first use (QRF, qFEP, BMR, EFE, and the rest).
- The abstract is plain prose: one composed paragraph, no per-track headings,
  no inline formulas. Keep abstract fragments formula-free.

## Figures

- Embed as `![short](../output/figures/<id>.png){#fig:<id>}`. The short caption
  is overwritten at compose time by the canonical caption in `figures.yaml`.
- Each canonical caption must be at least 120 characters and contain both an
  interpretive-boundary term and an encoding term.
- Cross-reference with `@fig:`, `@sec:`, `@eq:`. Never write a hardcoded
  "Figure 3" (the reference audit fails on `Figure <number>`).
- Placement is gated: QRF lead figures appear in the main text and are ordered
  before the compact quantum summary; technical-quantum and governance figures
  appear only in the supplement; supplement figures must not duplicate main or
  cover figures.

## Subsection titles

Per-track subsection titles come from `sheaf/tracks.yaml` `section_titles`.
Each must be at least four words and must not be a generic title (for example
"Results", "Methods", "Validation", "Limitations", "QRF deployment",
"Visual evidence"). The subsection-title audit requires at least 20 qualifying
titles overall.

## No machine paths

Use repository-relative paths only. No absolute `/Users/` paths anywhere.
